# Monster Maker V2 · V1 UX 패리티 기준

## 판정 기준

- 동일: 같은 위치와 같은 조작 단계로 사용할 수 있다.
- 개선: 작업 단계는 같고, 상태·실수 방지·가독성이 더 좋아졌다.
- 단순화: 데이터는 만질 수 있지만 V1의 전용 조작 UX가 빠졌다.
- 누락: V1에서 가능한 작업을 V2에서 할 수 없다.

기본 PropertyField로 직렬화 데이터를 노출한 것만으로는 동일로 판정하지 않는다.
사용자가 실제로 하던 선택, 조립, 미리보기, 위치 보정, 오류 복구 흐름이 있어야 한다.

## 안전·유지보수 기준

- V2는 영구 Draft와 분리된 DontSave 작업 사본만 편집한다.
- 창 직렬화값과 SessionState의 이중 복구를 사용하고, 복구된 Dirty는 저장·폐기 전까지 유지한다.
- 원본 저장 전에는 영구 Draft, Definition, Catalog를 수정하지 않는다.
- 외부에서 원본 파일이 바뀌면 지문 비교로 덮어쓰기를 거부한다.
- 전투 반영은 공용 MonsterMakerValidator와 MonsterMakerAssetWriter만 사용한다.
- V1 MonsterMakerWindow를 숨겨서 그리는 호스팅 방식은 최종 구조로 인정하지 않는다.
- 전체 창 배치는 UXML/USS에서 조절하고, PreviewRenderUtility가 필요한 렌더 표면만
  IMGUIContainer를 사용한다.
