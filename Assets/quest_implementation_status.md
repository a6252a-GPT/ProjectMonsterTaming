## 1. 현재 Unity 프로젝트 상태

현재 퀘스트 기능은 작업 전 단계에 가깝습니다.

- `Assets/ProjectMT/03_Features/Quest` 폴더는 존재하지만 실제 퀘스트 스크립트·프리팹·데이터가 확인되지 않음
- `TutorialUnlock` 폴더에도 실제 구현 파일이 확인되지 않음
- 퀘스트 진행도 저장 데이터 없음
- 퀘스트 조건 판정 코드 없음
- 퀘스트 보상 수령 코드 없음
- 일일·주간 퀘스트 초기화 코드 없음
- 퀘스트 UI 없음
- 퀘스트에 따른 콘텐츠 해금 연결 없음

원정대 스테이지 해금이나 성장 던전 단계 해금 로직은 존재하지만, 이는 퀘스트 시스템이 아니라 콘텐츠 자체의 진행도 처리입니다.

| 영역 | 현재 상태 |
|---|---|
| 메인 퀘스트 | 미구현 |
| 퀘스트 데이터 | 미구현 |
| 퀘스트 진행도 | 미구현 |
| 퀘스트 보상 수령 | 미구현 |
| 일일·주간 퀘스트 | 미구현 |
| 퀘스트 UI | 미구현 |
| 튜토리얼 | 미구현 |
| 기능 해금 연동 | 미구현 |

Notion 기능명세서에서도 퀘스트 관련 기능은 모두 `미구현`으로 표시되어 있으며, Unity 프로젝트 확인 결과와 일치합니다.

## 2. 기획서의 기본 유저 흐름

기획서의 기본 진행 순서는 다음과 같습니다.

> 첫 몬스터 획득 → 원정대 → 퀘스트 → 몬스터 뽑기 → 부대 편성 → 몬스터 강화 → 장비 장착 → 장비 슬롯 강화 → 군단장 스킬 → 잠재능력 → 일일·주간 퀘스트

## 3. 메인 퀘스트 기준

- 한 번에 메인 퀘스트 1개만 진행
- 조건을 달성하면 완료 상태로 변경
- 완료 후 보상 버튼을 눌러야 보상 획득
- 보상을 받은 뒤 다음 퀘스트 시작
- 퀘스트 진행에 따라 성장 기능을 순차적으로 해금

예시 흐름:

1. 원정대 1회 클리어
2. 퀘스트 완료
3. 보상 수령
4. 몬스터 뽑기 기능 해금
5. 다음 퀘스트 시작

## 5. 튜토리얼 순서

기획서의 필수 튜토리얼 순서는 다음과 같습니다.

1. 원정대 진행
2. 보상 수령
3. 몬스터 뽑기
4. 부대 편성
5. 몬스터 강화
6. 장비 장착
7. 장비 슬롯 강화
8. 군단장 스킬 획득
9. 군단장 스킬 장착
10. 군단장 스킬 사용
11. 잠재능력
12. 일일·주간 퀘스트

추가 기준:

- 기능 설명뿐 아니라 실제 조작까지 안내
- 조작 후 결과가 반영되는 것까지 확인
- 튜토리얼 중에도 메인 전투는 계속 진행
- 튜토리얼 건너뛰기 기능은 현재 보류

## 결론

현재 퀘스트는 UI를 보완하는 수준이 아니라 다음 시스템을 새로 구현해야 하는 상태입니다.

- 퀘스트 데이터
- 진행도 관리
- 조건 이벤트 감지
- 보상 수령
- 퀘스트 저장
- 기능 해금
- 메인 퀘스트 UI
- 튜토리얼
- 일일·주간 초기화

팀장님이 몬스터 스킬·군단장 스킬·성 침공을 담당한다면, 퀘스트는 별도 작업 항목으로 잡아야 합니다. 우선순위는 `QUEST-03` → `QUEST-01` → `QUEST-10` → `QUEST-11` 순서로 시작하고, 이후 튜토리얼과 일일·주간 퀘스트를 연결하는 방식이 적합합니다.
