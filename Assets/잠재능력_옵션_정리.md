# 잠재능력 옵션 정리

## 기준

현재 프로젝트 문서 기준으로 잠재능력은 모든 편성 몬스터에 공통 적용되는 **5슬롯 옵션 시스템**이다.

- 슬롯 1개에는 옵션 1개가 적용된다.
- 같은 옵션(`StatId`)은 최대 2슬롯까지 중복될 수 있다.
- 공격력 범위형 옵션은 잠재능력 대상에서 제외한다.
- 잠재능력 전용 옵션표와 최종 수치는 아직 완전히 확정되지 않았다.
- 임시 기준으로는 장비 랜덤 옵션 목록과 기본 수치를 재사용하고, 등급 배율을 적용한다.

## 잠재능력 옵션 종류 및 기본 수치

| 옵션 종류 | 기본 수치 |
|---|---:|
| 공격력 | +2% |
| 방어력 | +2% |
| HP | +2% |
| 공격 속도 | +1% |
| 이동 속도 | +0.5% |
| 치명타 확률 | +1%p |
| 치명타 피해 | +5%p |
| 스킬 피해 | +2% |
| 보스 피해 | +2% |
| 일반 몬스터 피해 | +2% |
| 쿨타임 감소 | +1%p |
| 방어력 관통 | +2%p |
| 피해 감소 | +1%p |

> `%`와 `%p`는 구분한다. 퍼센트포인트(`%p`) 옵션은 확률·피해율 등의 최종 비율에 직접 더하는 방식으로 해석한다.

## 등급 확률

| 등급 | 확률 |
|---|---:|
| 일반(Common) | 50% |
| 레어(Rare) | 30% |
| 에픽(Epic) | 15% |
| 레전더리(Legendary) | 4% |
| 신화(Mythic) | 1% |

## 재설정 및 잠금 비용

재설정 시 잠근 슬롯 수에 따라 잠재능력 재화가 소모된다.

| 잠금 슬롯 수 | 필요 재화 |
|---:|---:|
| 0개 | 1 |
| 1개 | 2 |
| 2개 | 4 |
| 3개 | 8 |
| 4개 | 16 |
| 5개 | 재설정 불가 |

## 장비 랜덤 옵션 그룹 기준

잠재능력 옵션을 장비 옵션표에서 재사용할 경우, 문서의 장비 랜덤 옵션 그룹 가중치는 다음과 같다.

| 옵션 그룹 | 가중치 |
|---|---:|
| 핵심 스탯 | 50% |
| 공격 특수 | 30% |
| 유틸/방어 | 20% |

## 미정 및 추후 확정 필요 항목

- 잠재능력 전용 옵션의 최종 목록
- 등급별 옵션 수치 배율
- 등급별 옵션 등장 가중치 및 중복 처리 방식
- 옵션별 최대 수치 또는 슬롯별 성장 상한
- 잠재능력 재설정 재화의 실제 명칭과 수급량

현재 밸런스 테스트용 임시 기준으로는 위 기본 수치를 사용하고, 등급 배율은 별도 밸런스 시트에서 관리하는 방식이 적합하다.
