# 몬스터 키우기 장비 시스템 작업 정리

## 작업 범위

이번 작업은 장비 시스템 중 **P0와 P1 기능을 먼저 구현**하는 것을 기준으로 한다.

문서상 장비 관련 P1 기능은 다음과 같다.

- `EQUIP-01` 장비 파밍 획득
- `EQUIP-02` 장비 인벤토리
- `EQUIP-03` 장비 장착·교체
- `EQUIP-06` 장비 부위 슬롯 영구 강화

장비 분해, 오프라인 자동분해, 오프라인 보상 결과 UI는 P2 범위이므로 이번 작업에서는 제외한다.

다만 P1 기능을 구현하려면 장비 데이터, 저장, 능력치 계산처럼 문서상 별도 장비 기능 ID로 구분되지 않은 공통 기반이 먼저 필요하다. 따라서 이 기반 작업을 장비 작업의 P0 선행 단계로 정리한다.

## 이번 수정으로 확정된 장비 규칙

이번 팀 확인 내용을 기준으로 장비 시스템은 다음 규칙을 적용한다.

### 장비 LV 관련

- 현재 작업 단계에서는 개별 장비 LV 기능을 구현하지 않는다.
- 장비창 사진에 보이는 Lv. 표기는 임시 표시이므로 실제 장비 데이터와 연결하지 않는다.
- 사진의 Lv. 표기는 슬롯 LV를 의미하지 않는다.
- 장비 데이터에 개별 장비 LV 필드를 추가하지 않는다.
- 기존 P1 범위에 포함된 EQUIP-06 장비 부위 슬롯 영구 강화는 유지하되, 강화 상태는 임시 Lv. 표기와 별도 데이터로 관리한다.

### 장비 능력치 적용 대상

- 장비를 장착했을 때 증가하는 능력치는 장비를 장착한 군단장에게만 적용한다.
- 몬스터 능력치, 몬스터 편성 부대 능력치, 몬스터 전투력에는 장비 능력치를 적용하지 않는다.

### 장비 부위

장비 부위는 다음 6개를 사용한다.

- 무기
- 투구
- 갑옷
- 장갑
- 신발
- 반지(악세서리)

각 부위는 동일 확률로 드랍한다. 부위별 확률은 6분의 1, 약 16.67%다.

### 동일 장비 중첩 보관 규칙

- 현재 장비는 개별 장비 LV나 랜덤 옵션을 사용하지 않고, 부위와 등급에 따라 능력치가 고정된다.
- 따라서 같은 부위와 같은 등급의 장비는 하나의 장비 종류로 취급한다.
- 장비 종류 키는 `부위 + 등급` 조합으로 구분한다. 예: `Weapon_Common`, `Weapon_Rare`.
- 같은 장비 종류를 여러 개 획득하면 인벤토리에는 동일한 항목을 여러 개 만들지 않고 하나만 표시한다.
- 첫 번째 장비는 대표 장비 항목으로 표시하고, 추가 획득분은 중첩 수량으로 기록한다.
- 예를 들어 일반 무기 3개를 획득하면 인벤토리에는 일반 무기 1개만 표시하고, 중첩 수량은 `+2`, 총 보유 수량은 3개로 기록한다.
- 내부 저장의 기준 수량은 대표 장비 1개를 포함한 총 보유 수량으로 관리하고, UI에는 필요에 따라 `중첩 +2` 또는 `보유 3개`로 표시한다.
- 같은 부위라도 등급이 다르면 별도 장비 종류로 보관한다. 예: 일반 무기와 희귀 무기는 서로 중첩하지 않는다.
- 같은 등급이라도 부위가 다르면 별도 장비 종류로 보관한다. 예: 일반 무기와 일반 투구는 서로 중첩하지 않는다.
- 장비 6개를 드랍할 때는 각 장비의 부위와 등급을 먼저 독립적으로 판정한 뒤, 동일한 장비 종류가 있으면 기존 스택에 수량을 합산한다.

### 부위·등급별 장비 능력치

장비 능력치는 장비의 부위와 등급 조합으로 결정한다. 현재 단계에서는 별도 랜덤 옵션을 추가하지 않고, 아래 수치를 고정 능력치로 사용한다.

| 장비 부위 | 적용 능력치 | Common 일반 | Rare 희귀 | Epic 영웅 | Legendary 전설 | Mythic 신화 |
|---|---|---:|---:|---:|---:|---:|
| 무기 | 공격력 | +10 | +20 | +30 | +40 | +50 |
| 투구 | 최대 체력 | +100 | +200 | +300 | +400 | +500 |
| 갑옷 | 방어력 | +10 | +20 | +30 | +40 | +50 |
| 장갑 | 공격속도 | +0.5 | +0.6 | +0.7 | +0.8 | +0.9 |
| 신발 | 이동속도 | +0.5 | +0.6 | +0.7 | +0.8 | +0.9 |
| 반지(악세서리) | 치명타 | +10 | +20 | +30 | +40 | +50 |

예를 들어 `Rare 무기`는 공격력 `+20`, `Mythic 투구`는 최대 체력 `+500`을 제공한다. 장비 효과는 장착한 군단장에게만 적용한다.

### 장비 등급 및 드랍 확률

| 등급 | 영어 표기 | 드랍 확률 |
|---|---|---:|
| 일반 | Common | 68% |
| 희귀 | Rare | 20% |
| 영웅 | Epic | 8% |
| 전설 | Legendary | 3% |
| 신화 | Mythic | 1% |
| 합계 |  | 100% |

몬스터 등급과 동일하게 5개 등급만 사용하며, Uncommon 등 별도 등급은 추가하지 않는다.

### 장비 드랍 조건

- 장비는 메인 전투의 원정대 스테이지 클리어 결과로 획득한다.
- 원정대 10스테이지부터 5스테이지 간격으로 장비 드랍 판정을 실행한다.
- 장비 드랍 대상 스테이지는 10, 15, 20, 25, 30 …이다.
- 대상 스테이지를 클리어하면 장비를 정확히 6개 생성한다.
- 6개 장비 각각에 대해 부위를 독립적으로 1회 판정한다.
- 6개 장비 각각에 대해 등급을 독립적으로 1회 판정한다.
- 각 장비의 능력치는 판정된 부위와 등급의 조합으로 결정한다.
- 같은 스테이지에서 같은 부위가 여러 번 나올 수 있다. 예를 들어 무기 3개, 장갑 1개, 투구 1개, 신발 1개가 나올 수 있다.
- 같은 부위라도 장비마다 등급이 다르게 나올 수 있다. 예를 들어 일반 무기, 희귀 무기, 영웅 무기가 함께 나올 수 있다.
- 대상이 아닌 스테이지에서는 장비 드랍을 실행하지 않는다.
- 장비 6개를 보상 목록에 추가한 뒤 인벤토리 최대 수량과 가득 참 처리 규칙을 적용한다.

### 인벤토리 수량

- 인벤토리 최대 수량은 현재 설정을 그대로 유지한다.
- 이번 작업에서는 인벤토리 최대 수량을 확장하거나 변경하지 않는다.
- 동일 장비가 중첩될 경우 인벤토리 목록에는 하나의 항목만 표시하고, 중첩 수량은 해당 항목의 데이터로 관리한다.

## 현재 프로젝트 상태

팀원이 제작한 내용은 현재 **장비창 UI와 기본 화면 연결 중심**이다.

### 현재 확인된 부분

- 메인 메뉴에서 장비창 열기
- 장비창 닫기
- `PF_CommanderEquipmentPage` 프리팹
- 군단장 미리보기 영역
- 장비 슬롯 6개 UI
  - 무기
  - 투구
  - 갑옷
  - 장갑
  - 반지
  - 신발
- 보유 장비 목록 UI
- 장비 부위 필터 UI
- 장착 가능 장비 우선·등급순 정렬 문구
- 선택 장비 정보 영역
- 장착 버튼 UI

### 아직 필요한 부분

현재 장비창은 실제 장비 데이터와 연결되지 않은 UI 중심 상태다.

- 장비 데이터 생성 및 보유 목록 연결
- 장비 드랍 및 보상 지급
- 장비 선택 및 상세 정보 표시
- 필터·정렬 기능 연결
- 장비 장착·교체
- 장비 능력치 반영
- 슬롯 강화
- 저장 및 재접속 유지

장비 프리팹 내부에서 실제 Unity 버튼 이벤트가 연결된 부분도 제한적이므로, 화면에 보이는 버튼을 기능과 연결하는 작업이 필요하다.

사진에 표시된 Lv. 문구는 임시 UI이므로 현재 장비 작업 범위에서 제외한다. 해당 표시를 장비 레벨이나 슬롯 강화 레벨로 해석하지 않는다.

# P0 선행 작업

P0는 실제 장비 획득·장착 기능을 구현하기 전에 먼저 확정하고 만들어야 하는 공통 기반이다.

## P0-1. 확정 장비 규칙을 데이터에 반영

위에서 확정한 팀 규칙을 데이터와 보상 판정 기준에 반영한다.

- 개별 장비 LV를 구현하지 않는다.
- 장비창의 임시 Lv. 표기를 장비 데이터나 슬롯 강화 데이터와 연결하지 않는다.
- 장비 등급은 Common, Rare, Epic, Legendary, Mythic 5개만 사용한다.
- 등급 확률은 68%, 20%, 8%, 3%, 1%을 사용한다.
- 장비 부위는 무기, 투구, 갑옷, 장갑, 신발, 반지 6개를 사용한다.
- 부위별 확률은 각각 6분의 1로 동일하게 적용한다.
- 메인 전투의 원정대 10, 15, 20, 25 … 스테이지 클리어 때만 장비 드랍 판정을 실행한다.
- 대상 스테이지마다 장비 6개를 지급한다.
- 장비 6개는 각각 부위와 등급을 독립적으로 판정한다.
- 부위와 등급에 따른 능력치는 확정된 부위·등급별 수치표를 사용한다.
- 인벤토리 최대 수량은 기존 설정을 유지한다.
- 장비 능력치는 군단장에게만 적용한다.

아직 별도로 정해야 하는 값은 장비 해제 허용 여부, 교체 시 기존 장비 처리 방식, 슬롯 영구 강화 비용과 성장 수치, 인벤토리가 가득 찼을 때 6개 보상을 처리하는 상세 방식이다.

## P0-2. 장비 데이터 구조 제작

장비 종류와 보유 중첩 수량을 식별하고 저장할 수 있는 데이터 구조를 만든다.

### 장비 데이터에 필요한 값

- 장비 종류 키 또는 장비 정의 ID
- 장비 이름
- 장비 부위
- 장비 아이콘
- 장비 등급
- 부위·등급으로 결정되는 고정 능력치
- 획득 경로
- 장착 가능 조건
- 세트 정보가 있다면 세트 ID
- 장비 부위 슬롯 영구 강화 상태와 수치가 있다면 별도 관리

개별 장비에는 LV 필드를 넣지 않는다. 장비창의 임시 Lv. 표기는 실제 장비 데이터와 연결하지 않는다.

현재 단계에서는 별도 랜덤 옵션을 생성하지 않는다. 능력치는 부위와 등급에 따라 위의 확정 수치표에서 결정한다.

장비는 같은 종류가 여러 개 나올 수 있으므로, 카탈로그에 있는 장비 정의와 실제 보유 장비 스택을 구분한다.

- **장비 카탈로그:** 이름, 아이콘, 부위, 등급, 부위·등급별 고정 능력치 등 고정 정보
- **보유 장비 스택:** 장비 종류 키, 총 보유 수량, 사용 가능한 수량, 장착 상태 또는 장착 수량 등 보유 정보
- 동일 부위·등급의 장비를 획득하면 새 보유 항목을 만들지 않고 해당 장비 스택의 수량을 1 증가시킨다.
- 장비 목록에는 장비 스택 하나당 대표 항목 하나만 생성한다.

## P0-3. 장비 보유·저장 기반 제작

장비를 획득하고 장착한 뒤 재접속해도 유지되도록 보유 데이터와 저장 구조를 만든다.

### 저장해야 하는 값

- 보유 장비 스택 목록
- 각 스택의 장비 종류 키 또는 장비 정의 ID
- 장비 부위
- 장비 등급
- 부위·등급으로 결정된 고정 능력치
- 각 장비 스택의 총 보유 수량
- 장착에 사용 중인 수량 또는 장비 스택별 사용 가능 수량
- 군단장별 부위별 장착 장비 종류 키
- 부위별 슬롯 영구 강화 상태 또는 수치
- 인벤토리 최대 수량
- 장비 획득 기록
- 장비를 획득한 원정대 스테이지

개별 장비 LV와 장비창의 임시 Lv. 표기는 저장하지 않는다.

장비 획득, 중첩 수량 증가, 장착, 교체, 강화가 끝난 뒤 저장하고, 재접속 시 저장된 장비 스택과 장착 상태를 다시 불러오는 구조로 만든다.

## P0-4. 장비 능력치 계산 기반 제작

장비창에서 수치만 바뀌는 것이 아니라 실제 전투 데이터에 적용될 수 있도록 능력치 계산 연결 지점을 정한다.

기본 흐름은 다음과 같이 구성한다.

장착 장비 데이터
      ↓
장비 능력치 합산
      ↓
군단장 능력치 계산
      ↓
군단장 상세 능력치·총전투력
      ↓
장비창 및 군단장 관련 전투 데이터

장비 능력치는 군단장에게만 적용한다. 몬스터 능력치, 몬스터 편성 부대 능력치, 몬스터 전투력 또는 몬스터용 전투 스냅샷에는 장비 능력치를 전달하지 않는다.

우선 연결할 능력치는 다음과 같다.

- 무기: 공격력
- 투구: 최대 체력
- 갑옷: 방어력
- 장갑: 공격속도
- 신발: 이동속도
- 반지(악세서리): 치명타
- 총전투력

장비 효과는 군단장 능력치 계산에만 반영한다.

## P0 작업 완료 기준

- 장비 부위와 등급 규칙이 확정되어 있다.
- 장비 드랍 대상 스테이지와 등급·부위 확률이 적용되어 있다.
- 개별 장비 LV와 임시 Lv. 표기를 데이터와 연결하지 않는다.
- 장비 카탈로그와 보유 장비 스택이 구분되어 있다.
- 장비 종류 키와 장비 스택 수량을 저장할 수 있다.
- 동일 부위·등급 장비를 개별 항목으로 나누지 않고 하나의 스택으로 합산할 수 있다.
- 군단장별 장착 장비와 슬롯 영구 강화 상태를 저장할 수 있다.
- 재접속 후 보유 장비와 장착 상태가 복원된다.
- 장비 능력치를 합산할 수 있다.
- 장비 능력치가 군단장에게만 적용되는 위치가 정해져 있다.

# P1 실제 작업 순서

P1은 아래 순서대로 작업하는 것이 좋다. 장비를 먼저 획득하고 보유할 수 있어야 장비창과 장착 기능을 테스트할 수 있다.

## 1단계. `EQUIP-01` 장비 획득·드랍 구현

메인 전투의 원정대 스테이지 클리어 결과를 확인해 장비를 지급하는 기능을 만든다.

### 구현할 내용

- 메인 전투의 원정대 스테이지 클리어 결과 확인
- 10스테이지부터 5스테이지 간격으로 장비 드랍 대상 판정
- 장비 드랍 대상: 10, 15, 20, 25, 30 …
- 대상 스테이지 클리어 시 장비 6개 생성
- 생성된 6개 각각에 대해 Common 68%, Rare 20%, Epic 8%, Legendary 3%, Mythic 1% 등급 판정
- 생성된 6개 각각에 대해 무기·투구·갑옷·장갑·신발·반지 6부위 균등 판정
- 부위와 등급 조합에 따른 고정 능력치 적용
- 장비 획득 시 부위와 등급 조합으로 장비 종류 키 생성
- 동일 장비 종류가 이미 있으면 기존 스택 수량을 1 증가
- 동일 장비 종류가 없으면 새 장비 스택 항목을 보유 목록에 추가
- 장비 획득 결과 표시
- 보상 중복 지급 방지
- 인벤토리가 가득 찼을 때 처리
- 개별 장비 LV를 생성하거나 저장하지 않음

6개 장비의 부위는 서로 제한 없이 중복될 수 있다. 예를 들어 무기 3개, 장갑 1개, 투구 1개, 신발 1개가 한 번에 지급될 수 있다. 각 장비의 등급도 독립적으로 판정하므로 일반 무기와 희귀 무기처럼 같은 부위의 여러 등급이 함께 나올 수 있다. 보상 6개를 인벤토리에 반영할 때는 각 장비의 부위·등급 조합을 확인해 같은 장비 종류가 있으면 하나의 스택으로 합친다. 예를 들어 일반 무기 3개가 나오면 인벤토리에는 일반 무기 항목 1개만 남고 중첩 수량이 `+2` 증가한다.

장비 지급 로직은 특정 UI에 직접 넣지 않고, 메인 전투 클리어 보상에서 호출할 수 있는 공통 보상 처리 방식으로 만든다. 오프라인 보상이나 다른 콘텐츠로 장비 획득 경로를 확장하는 것은 P2 이후에 별도로 연결한다.

### 완료 기준

- 원정대 10, 15, 20, 25 … 스테이지를 클리어하면 장비 드랍 판정이 실행된다.
- 대상이 아닌 스테이지에서는 장비가 드랍되지 않는다.
- 대상 스테이지마다 장비 6개가 지급된다.
- 6개 각각의 부위가 독립적으로 판정되며 동일 부위가 여러 개 나올 수 있다.
- 6개 각각의 등급이 독립적으로 판정되며 같은 부위의 여러 등급이 함께 나올 수 있다.
- 등급 확률 68%, 20%, 8%, 3%, 1%이 정상 적용된다.
- 6개 장비 부위가 동일 확률로 선택된다.
- 같은 부위·등급의 장비가 여러 번 나오면 인벤토리의 하나의 장비 스택으로 합쳐진다.
- 일반 무기 3개 획득 시 일반 무기 항목 1개와 중첩 `+2`가 표시되거나 저장된다.
- 같은 부위·등급 장비의 총 보유 수량이 정확히 누적된다.
- 장비 부위와 등급에 맞는 고정 능력치가 정확히 적용된다.
- 장비 획득 후 보유 수량이 증가한다.
- 재접속해도 획득한 장비가 유지된다.
- 인벤토리 가득 참 처리 결과가 명확하게 표시된다.

## 2단계. `EQUIP-02` 장비 인벤토리 연결

획득한 장비를 현재 장비창의 보유 목록에 표시한다.

### 구현할 내용

- 보유 장비 목록 생성
- 장비 획득 후 목록 갱신
- 장비 아이콘과 등급 표시
- 장비 부위 표시
- 부위·등급에 따른 고정 능력치 표시
- 장비창의 임시 Lv. 표기는 현재 형태로 두고 실제 데이터와 연결하지 않음
- 장비 선택
- 선택 장비 상세 정보 표시
- 같은 장비 종류는 인벤토리 목록에 한 번만 표시
- 장비 스택의 총 보유 수량 또는 추가 중첩 수량 표시
- 전체 장비 필터
- 부위별 필터
- 장착 가능 장비 우선 정렬
- 등급순 정렬
- 보유 수량 표시
- 빈 슬롯 표시
- 보유 장비가 없을 때 빈 화면 표시
- 장비 선택 해제
- 기존 인벤토리 최대 수량 표시와 제한 유지
- 동일 부위·등급 장비 획득 시 기존 목록 항목의 중첩 수량만 갱신

### 완료 기준

- 획득한 장비가 장비창 목록에 표시된다.
- 장비 목록에서 장비를 선택할 수 있다.
- 선택한 장비의 이름, 부위, 등급, 능력치가 상세 영역에 표시된다.
- 선택한 장비의 능력치는 부위·등급별 확정 수치와 일치한다.
- 같은 부위·등급 장비가 여러 개 있어도 목록에는 하나의 항목만 표시된다.
- 일반 무기 3개를 보유하면 일반 무기 1개와 중첩 `+2` 또는 총 보유 수량 3개가 표시된다.
- 같은 부위·등급 장비를 추가 획득하면 새 목록 항목이 생기지 않고 기존 스택 수량이 증가한다.
- 부위가 다르거나 등급이 다른 장비는 서로 다른 목록 항목으로 표시된다.
- 필터를 변경하면 해당 부위 장비만 표시된다.
- 정렬 기준을 변경하면 목록 순서가 바뀐다.
- 임시 Lv. 표기가 장비 데이터나 슬롯 강화 상태를 변경하지 않는다.
- 장비가 없거나 목록이 가득 찬 상태에서도 UI가 깨지지 않는다.

## 3단계. `EQUIP-03` 장비 장착·교체 구현

인벤토리에서 선택한 장비를 올바른 슬롯에 장착한다.

장비 장착 대상은 군단장이며, 장비 장착으로 증가하는 능력치도 군단장에게만 적용한다. 몬스터 편성 부대에는 장비 장착 효과를 전달하지 않는다.

### 구현할 내용

- 무기는 무기 슬롯에만 장착
- 투구는 투구 슬롯에만 장착
- 갑옷은 갑옷 슬롯에만 장착
- 장갑은 장갑 슬롯에만 장착
- 반지는 반지 슬롯에만 장착
- 신발은 신발 슬롯에만 장착
- 장비 부위가 다른 슬롯에는 장착되지 않도록 제한
- 장착 버튼 이벤트 연결
- 장착 시 선택한 장비 스택의 사용 가능한 수량 1개를 장착 상태로 반영
- 장착 전후 능력치 비교
- 이미 장착된 장비 교체
- 교체된 기존 장비를 동일 장비 종류의 인벤토리 스택으로 반환
- 장착 중인 장비 표시
- 장착 불가능한 장비의 버튼 비활성화
- 장착 상태에 따른 목록·슬롯 갱신

장비 해제를 허용할지 여부는 P0-1에서 정한 규칙을 적용한다. 해제를 허용하지 않는다면 교체만 가능하게 하고, 해제를 허용한다면 빈 슬롯 상태까지 처리한다.

### 완료 기준

- 각 장비가 올바른 부위 슬롯에만 장착된다.
- 장착 장비가 해당 군단장의 장비 슬롯에 표시된다.
- 이미 장착된 장비를 새 장비로 교체할 수 있다.
- 교체된 장비가 사라지지 않고 해당 장비 종류의 인벤토리 스택 수량으로 돌아온다.
- 보유 수량이 없는 장비 스택은 장착할 수 없고, 장착 시 사용 가능한 수량이 정확히 반영된다.
- 장착한 장비의 능력치가 군단장에게만 반영된다.
- 몬스터 능력치와 몬스터 편성 부대 능력치는 변경되지 않는다.
- 장착 상태가 장비창을 닫았다가 다시 열어도 유지된다.
- 재접속 후에도 장착 상태가 유지된다.

## 4단계. 장비 능력치·총전투력 반영

장비 장착 결과를 군단장의 실제 능력치와 전투력에 연결한다.

### 구현할 내용

- 군단장 장비 장착 시 군단장 능력치 증가
- 장비 교체 시 기존 장비의 군단장 능력치 제거
- 장비 해제 시 군단장 능력치 제거
- 장비 능력치 합산
- 군단장 능력치 갱신
- 군단장 총전투력 갱신
- 장비창의 군단장 능력치 표시 갱신
- 군단장 관련 전투 데이터에 최신 능력치 전달
- 몬스터 능력치와 몬스터 편성 부대 능력치는 갱신하지 않음
- 몬스터용 전투 스냅샷에 장비 능력치를 포함하지 않음

### 완료 기준

- 장비 장착 전후 군단장 능력치가 실제로 달라진다.
- 장비 교체 시 이전 장비의 수치가 중복으로 남지 않는다.
- 장비창의 군단장 표시 수치와 실제 군단장 전투 수치가 일치한다.
- 장비 장착으로 몬스터 능력치가 변경되지 않는다.
- 전투 진입 후에도 장비 효과가 유지된다.
- 총전투력이 장비 변경에 따라 갱신된다.

## 5단계. `EQUIP-06` 장비 부위 슬롯 영구 강화

문서 기준 강화 대상은 개별 장비가 아니라 장비 부위 슬롯이다.

이 기능을 구현하더라도 장비창 사진의 임시 Lv. 표기를 슬롯 강화 표시로 사용하지 않는다. 슬롯 영구 강화 상태와 표시 방식은 별도 UI로 연결한다.

### 강화 대상

- 무기 슬롯
- 투구 슬롯
- 갑옷 슬롯
- 장갑 슬롯
- 반지 슬롯
- 신발 슬롯

### 구현할 내용

- 슬롯별 영구 강화 상태 또는 내부 강화 단계 저장
- 현재 강화 상태 표시
- 다음 강화 수치 표시
- 강화 비용 표시
- 골드 차감
- 강화석 차감
- 강화 버튼 이벤트 연결
- 재화 부족 시 강화 차단
- 최대 강화 단계 제한
- 강화 성공 후 능력치 증가
- 총전투력 갱신
- 강화 결과 저장
- 재접속 후 강화 상태 유지

### 완료 기준

- 각 부위 슬롯을 개별적으로 강화할 수 있다.
- 강화 비용이 부족하면 강화되지 않는다.
- 강화 후 재화가 정확히 차감된다.
- 강화한 슬롯의 효과가 해당 군단장의 장착 장비와 함께 적용된다.
- 강화 효과가 몬스터 능력치에 적용되지 않는다.
- 강화 상태와 능력치가 재접속 후에도 유지된다.

## 6단계. P1 최소 UI 연결 및 통합 테스트

P2의 전체 장비 관리 UI를 완성하기 전에, P1 기능을 검증하는 데 필요한 버튼과 표시만 먼저 연결한다.

### 연결할 UI

- 장비 목록 버튼
- 장비 선택 버튼
- 부위 필터 버튼
- 정렬 버튼
- 장착 버튼
- 강화 버튼
- 장착 슬롯 표시
- 능력치 비교 영역
- 총전투력 표시
- 장비 획득 결과 표시
- 임시 Lv. 표기는 기능과 연결하지 않고 현재 UI 상태 유지
- 저장 성공 여부를 확인할 수 있는 상태

### 통합 테스트

- 원정대 10·15·20·25 … 스테이지 클리어 → 장비 드랍 판정
- 대상이 아닌 스테이지 클리어 → 장비 미드랍
- 대상 스테이지 클리어 → 장비 6개 지급
- 6개 각각에 등급 확률표와 6부위 균등 확률 적용
- 6개 장비의 부위 중복 및 같은 부위의 등급 차이 확인
- 같은 부위·등급 장비 중첩 확인: 일반 무기 3개 → 목록 1개, 중첩 `+2`, 총 보유 3개
- 6개가 모두 같은 부위·등급이면 목록 1개와 중첩 `+5`로 합쳐지는지 확인
- 같은 부위지만 등급이 다르면 서로 다른 스택으로 분리되는지 확인
- 같은 등급이지만 부위가 다르면 서로 다른 스택으로 분리되는지 확인
- 부위·등급별 고정 능력치 확인
- 장비 획득 → 인벤토리 표시
- 인벤토리 선택 → 상세 정보 표시
- 장비 장착 → 슬롯 변경
- 장비 교체 → 기존 장비 인벤토리 반환
- 장비 장착 → 군단장 능력치·전투력 증가
- 장비 장착 → 몬스터 능력치·편성 부대 능력치 변화 없음
- 슬롯 강화 → 재화 차감 및 능력치 증가
- 임시 Lv. 표기 → 장비 데이터와 슬롯 강화 상태 변화 없음
- 장비창 닫기·재진입 → 상태 유지
- 게임 재실행 → 장비·장착·강화 상태 유지

- 동일 장비 중첩 획득 → 인벤토리 항목은 늘지 않고 스택 수량만 증가

# 이번 수정 후 확정된 기준

이번 팀 확인으로 아래 항목은 확정된 것으로 반영한다.

- 현재 단계에서는 개별 장비 LV 기능을 구현하지 않는다.
- 장비창 사진의 임시 Lv. 표기는 슬롯 LV가 아니며, 실제 데이터와 연결하지 않는다.
- 장비 능력치는 군단장에게만 적용한다.
- 몬스터 및 몬스터 편성 부대에는 장비 능력치를 적용하지 않는다.
- 장비 등급은 일반(Common), 희귀(Rare), 영웅(Epic), 전설(Legendary), 신화(Mythic) 5개다.
- 등급 확률은 68%, 20%, 8%, 3%, 1%다.
- 장비 부위는 무기, 투구, 갑옷, 장갑, 신발, 반지(악세서리) 6개다.
- 부위별 드랍 확률은 각각 6분의 1로 동일하다.
- 장비는 메인 전투의 원정대 10스테이지부터 5스테이지 간격으로 드랍한다.
- 대상 스테이지를 클리어할 때마다 장비 6개를 지급한다.
- 6개 장비의 부위와 등급은 각각 독립적으로 랜덤 판정하며 부위 중복을 허용한다.
- 장비 능력치는 부위·등급별 확정 수치표를 사용한다.
- 같은 부위·등급 장비는 인벤토리에서 하나의 항목으로 중첩 보관한다.
- 일반 무기 3개 획득 시 일반 무기 1개와 중첩 `+2`를 기록하고, 총 보유 수량은 3개로 관리한다.
- 같은 부위·등급 장비를 추가 획득하면 기존 스택 수량을 증가시키며 새 인벤토리 항목을 만들지 않는다.
- 부위가 다르거나 등급이 다른 장비는 서로 중첩하지 않는다.
- 인벤토리 최대 수량은 현재 설정을 그대로 유지한다.

## 추가로 정할 값

P0·P1 구현 중 아래 수치는 별도로 정하면 된다.

- 장비 해제 허용 여부
- 장비 교체 시 기존 장비 처리 방식
- 슬롯 영구 강화 비용과 강화 수치
- 인벤토리가 가득 찼을 때의 상세 처리 방식

따라서 실제 구현 순서는 **장비 데이터·저장 기반 → 메인 전투 장비 드랍 → 인벤토리 → 군단장 장비 장착·교체 → 군단장 능력치 반영 → 슬롯 영구 강화 → UI·저장 테스트**로 진행한다.
